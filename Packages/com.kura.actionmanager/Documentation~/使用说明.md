# 王冠Kura · 动作管理器

## 安装

- **VCC / ALCOM**：Settings → Packages → Add Repository，粘贴

  ```
  https://GuiltyCrownsa.github.io/KuraActionManager/index.json
  ```

  然后在项目里勾选「Kura 动作管理器」安装；之后有新版本直接在这里点更新。
- **手动**：导入 Release 里的 `com.kura.actionmanager-<版本>.unitypackage`。

升级只会替换包内脚本，`Assets/KuraActionInstaller/` 下生成的动画、缩略图和配置不会被覆盖。

入口：Unity 顶部独立菜单 **王冠Kura → 动作管理器**。

1. 新建配置，拖入角色根物件（带 Avatar Descriptor 和有效 Humanoid Animator）。
2. 用分组列表的 ＋ 新建大菜单，默认名为“新建分组”；填写名称和容量，拖动可调整顺序。仅勾选“允许此分组动作同步”的分组参与同步发送和接收。
3. 选中分组，将 AnimationClip 或 FBX 拖到下方添加区。动作可改名、拖动排序、移到其他分组。
4. 勾选动作配乐后，每个动作可拖入自己的 AudioClip，并选择音乐是否循环。全套动作共用一个 AudioSource，由各动作状态的 VRC Animator Play Audio 在进入时停止旧音乐并播放对应配乐，退出时停止；无配乐动作保持静音。音乐开关只静音，不重新开始播放。
5. 按需勾选高度调整、头部固定、同步舞蹈。高度骨架根物件会自动查找，也可手动指定；0.5 为原高度，停止动作时恢复原高度。
6. 点击“生成并安装到角色”，然后保存场景。生成的物件包含 MA 组件，上传时由 Modular Avatar 合并。

设置入口只在总菜单第一页出现一次，位于末尾、→之前。首页分页时显示 6 个分组＋设置＋→；后续页和动作子菜单分页时显示 7 项＋→，末页最多 8 项。动作子菜单不放设置。

动作卡片左侧为缩略图，右侧为动作信息。可设置拍摄时间、拖入自己的图标，或启用“自动拍摄”。已选择角色时批量拖入动作会补拍图片，安装前也会补拍缺失图片；支持单独重拍及拍摄本组。256×256 PNG 保存到 Thumbnails 目录并用于 MA 菜单图标。拍摄使用独立渲染副本，按 MA 骨架映射跟随衣服，不改变场景角色。

参与同步的动作显示独立“同步 ID”和编码，未参与的显示“—”。ID 对应总动作顺序，调整动作或分组顺序会改变 ID。生成目录附带“同步ID对照表.txt”，用于核对双方的 ID、动作、分组及编码。

每套安装最多 255 个动作。容量是每个大菜单可容纳的动作数量，和每一页的 8 项上限不同；超出容量时会提示调整容量或移出动作，不会丢弃动作。

同步前缀默认 Kurasync，对应 Kurasync1–Kurasync8，也可自行修改。双方必须安装同一动作顺序、同步分组选择和前缀，且开启同步。手动选择动作优先于接收；取消手动动作后可跟随。协议沿用参考的 8 路二进制动作编号，适合同一范围内一位发起者，不提供歌曲时间轴的持续校准。

再次点击当前动作可停止。跟随同步时关闭“同步舞蹈”可停止跟随。

生成内容位于 Assets/KuraActionInstaller/Generated。每次使用独立目录，不覆盖原动作文件；安装标识用于隔离参数。已存在相同安装标识时可直接更新覆盖，生成成功后替换旧安装；失败保留旧安装。更新按配置重建，安装内手动修改不保留；旧资源目录保留以支持撤销和恢复。场景安装可使用 Unity 撤销移除，也可删除 KuraActions_安装标识 物件。删除物件后，已生成的独立资源仍保留，可以再手动清理。

如果角色已有另一套控制全身的动作系统，应先停用它再使用新系统，避免两套 Action 层互相覆盖。本插件不自动删除或停用用户现有的“动作”物件。

依赖：VRChat Avatars SDK、Modular Avatar。插件仅在 Editor 运行，角色上传无需携带自定义运行脚本。

## 动作镜像、速度与参数预览
在“安装与拍摄设置”中选装动作镜像和动画速度调整。生成后，总菜单的设置菜单内可切换 Humanoid 动作镜像，并用速度旋钮控制 0–2 倍播放：0% 暂停，50% 原速，100% 两倍速度。音乐随动作速度变化（音调也会随之变化）。Contact 同步仅传递动作 ID，舞蹈跟随者需自行保持相同镜像与速度设置。

安装设置底端仅显示本插件参数占用的 bit 数，随选装功能实时更新。镜像增加 1 bit，速度增加 8 bit；预览与实际 MA 参数使用同一份定义。显示的是本插件预算，不包含角色已有参数，最终以 MA 合并后的结果为准。修改安装选项后需重新生成安装，已有生成物件不会自动更新。

参数优化：Selected 改为本地 Int，Active 保持联网 Int；开启同步时使用联网 Bool Transmit 区分主动播放与跟随，避免转发收到的舞蹈。相对原版开启同步节省 7 bit，关闭同步节省 8 bit。已有安装需要移除后重新生成才能使用新参数布局。

## 随动作切换附属物件
“安装与拍摄设置”中开启“自动处理动画中的物件开关”。生成器会读取动作 AnimationClip 的 GameObject / m_IsActive 曲线，放入单独的 FX 物件控制器；原动画资源不改动，身体控制器使用去除显隐曲线的副本，避免重复控制。切换到其他动作或停止时，所有受控物件恢复安装时的 activeSelf 状态。

可以拖入“随安装复制的物件 Prefab”，并填写“动画原物件根路径”。例如原曲线是 动作/Wall，原根路径填 动作，Prefab 内有 Wall，安装后会自动重定向到新物件。没有 Prefab 的路径按角色根目录匹配。每个动作还可指定“附加物件开关动画”，用于与身体动作分开的显隐曲线；同一路径以身体动画的曲线为准。找不到的物件不会误操作其他对象，会写入生成目录的 未匹配物件.txt。

该功能控制物件显隐，不自动转换任意脚本、材质切换或自定义运行逻辑。物件控制与分段动作使用控制器内部参数，不增加联网 bit。配乐由独立状态层控制，不会在入场段切换循环段时重复播放。

原动作插件导入配置已迁移 5 组附属物件（麦克风、SlenderWheels、墙、摸头物件、水晶特效）和 3 个分段动作，保留旧同步标签与固定编号。Prefab 和附加显隐动画位于 ImportedObjects。旧控制器引用但旧场景不存在的路径会保留在迁移记录中，不会凭空生成物件。

## 模型配置记忆
拖入角色后自动恢复该场景模型之前使用的配置；首次使用的新模型在 Profiles 下创建独立空白配置。手动更换或新建配置会更新当前模型的关联。同名模型、同一 Prefab 的不同场景实例分别记录。已保存场景的关联保存在项目 ProjectSettings 下，关闭 Unity 后仍保留；未保存的新场景请先保存，以便下次恢复。

## 动作期间临时参数
安装与拍摄设置内可添加参数名与动作值。进入动作时保存原值、写入动作值，停止后恢复原值；连续切换动作不覆盖备份。Bool 的 0/1 表示关闭/开启，禁用型参数需填 1。当前 FaceEmo 使用 SYNC_CN_FORCE_BLINK_DISABLE=1 禁用眨眼。请使用其他插件的实际 Animator 参数名（留意 MA 重命名），不要填写 VRC 内置参数；参数应在最终控制器中存在。功能在进入和退出时写值，不会持续压制其他控制器对同一参数的写入。内部备份不占表情同步 bit，联网行为沿用目标参数原设置。更改列表后需重新生成安装。

缩略图按透明通道中的可见人物范围自动居中，并保留边距。旧缩略图需重新拍摄。物件控制器仅为有有效物件曲线的动作生成状态，无物件动作共用复位状态；整套配置无物件曲线时不生成该控制器。
配乐采用 3D 线性距离衰减：1 米以内保持设定音量，1–1.8 米逐渐衰减，1.8 米处降至静音。
多段动作：首段拖入入场动画，点击 ＋添加后续动画，拖入循环动画。本段循环选 循环；上一段播放进度 1 表示首段播完后过渡，过渡使用秒数勾选时可填写 0.1 秒。后续动画列表支持增删和排序，可继续添加多段。单次播放的末段结束后保持末帧，点击停止或切换动作退出；不会自动停止。循环设置仅修改生成副本，原动画不变。

界面页签：动作编排、缩略图、设置。播放与同步、物件与参数、安装选项统一位于设置页，参数占用显示在设置底部。


已用 SDK 实际约束求解验证跟随、固定、释放和第二次固定，并检查测试没有改变源角色骨骼。VRChat 的第一人称头部显示、多人网络表现仍需客户端实测；仅同步开关，后来加入的玩家不保证看到相同固定位置。需安装支持 VRC Constraints 的 SDK、Modular Avatar 和 NDMF。删除安装标记即可去除后续构建的固定功能，场景原骨架不受影响。
高度调整现在直接混合 Humanoid 动画的高度副本，不再使用 FX 层移动 Armature，也不需要 Rect Transform。50% 为原动作高度，0% 向下、100% 向上；保留原动作的上下运动和循环设置。范围按动画单位计算，实际世界距离随模型比例变化。启用高度会生成上下两份动作副本，原动画资源不变。
文件夹批量导入：动作编排页点击 从文件夹批量导入，或将 Project 中的文件夹拖到动作列表下方。支持 .anim 与模型内嵌动画、子文件夹扫描、按路径或动作名自然排序。每组数量可设 1–255，满组自动新建；已有分组保留。命名支持原名、自定义名称＋数字、数字＋自定义名称、原名＋数字，编号跨组连续。例如名称 抬腿、起始 4 得到 抬腿4、抬腿5；输入 抬腿姿势 则保留完整文字。导入前显示预览；排除预览动画和不支持的 Legacy 动画。单配置总数上限仍为 255，超限会阻止导入并提示。
